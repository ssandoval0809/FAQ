# 📝 FAQ Project - Frequently Asked Questions

Este es un proyecto de práctica de desarrollo web que muestra una página de preguntas frecuentes responsiva y accesible. El objetivo principal fue implementar **Flexbox** y **Media Queries**.

### 🚀 Cómo ejecutar el proyecto
Para ver la página web en tu computadora local, no necesitas instalar servidores complejos. Sigue estos pasos:

1. **Descarga los archivos:** Asegúrate de tener en una misma carpeta los archivos `index.html` y `styles.css`.

2. **Abre el archivo:**
  - Haz clic derecho sobre el archivo `index.html`.
  - Selecciona "Abrir con" y elige tu navegador preferido (Google Chrome, Firefox, Edge, etc.).

3. **Uso de herramientas de desarrollo:** Si deseas probar la responsividad, presiona F12 en tu teclado y activa la vista de dispositivos móviles.

### 🛠️ Tecnologías utilizadas
- **HTML5:** Uso de etiquetas semánticas (header, main, article) para mejor SEO.
- **CSS3:** Implementación de Flexbox y Media Queries.
- **Google Fonts:** Tipografía "Inter" para una lectura clara.

### 📋 Características principales
- **Diseño Responsivo:** Adaptado para celulares (640px), tabletas (1024px) y computadoras (1280px+).
- **Accesibilidad:**
    - Soporta navegación completa mediante teclado (tecla Tab).
    - Contraste de colores optimizado para lectura.
- **Interactividad:** Enlaces funcionales con estados visuales claros al pasar el cursor o hacer foco.
